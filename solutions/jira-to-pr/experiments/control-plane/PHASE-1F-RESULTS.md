## Trust boundaries

Schema versions 5 through 10 bind each observation and PR body update to the workflow, candidate, verification, publication, PR identity, and exact head commit, and store an initial-session create intent before the first OpenAI call. Required check name and GitHub App slug come from an immutable, separate trusted policy snapshot. A deferred PostgreSQL gate rejects `PASS` without exactly one successful record for each required exact-head check and enough current-head approvals from each reviewer's latest review. Observation reads the draft PR, base, branch, and commit tree before and after collecting check and review metadata. An unchanged repeated read reuses its batch; a result that returns after an intervening result gets a new immutable batch. Final evidence requires another live exact-head read and records the failed and passing check identities, results, and timestamps. Unknown GitHub and Agents API create outcomes fail closed.

Reviews and inline review comments are classified before storage or agent input. Raw bodies and CI logs are never stored in PostgreSQL. Only the exact allowlisted review code and trusted check remediation code can become repair input; other current-head review prose requires human attention. The repair input has a durable digest and idempotency key before Agents API submission. The new `CredentialProvider` interface preserves token isolation while allowing a future scoped GitHub App installation-token provider without changing publisher logic. Automatic merge and Jira integration are absent.

Initial-session recovery reads the saved Agents API root turn if a process stopped after PostgreSQL registered the session but before Candidate #1 was committed. If the process dies before local acknowledgement of session creation, a PostgreSQL intent and exact saved-session metadata allow read-only reconciliation. It requires one root turn in that session and a completed turn with the expected bounded artifact. Failed or ambiguous turns and unknown create outcomes stop without creating another session. Local tests cover these paths; a completed live initial-turn recovery has not yet been exercised.
