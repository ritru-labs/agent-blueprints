# Phase 1E scoped GitHub draft proof

**Result:** A real [draft PR #1](https://github.com/ritru-labs/agent-blueprints/pull/1) was created under `binnukyadari` against `feat/jira-to-pr-v0.1`. The [sanitized evidence](evidence/phase-1e-github-draft.json) records the exact run, candidate, independent verification, Git tree, branch commit, and PR linkage.

The trusted controller admitted the saved Phase 1A synthetic candidate into a new PostgreSQL run pinned to feature commit `875dc57bbede437cc806044d537e4b0e67be1527`. The Phase 1B Docker verifier returned `PASS` on that base. The publisher built a commit from the pinned base plus the three allowlisted candidate files, with only `sample/app.py` and `sample/tests/test_app.py` changed. GitHub readback confirmed branch commit `42b5c3669f7a836bf0a2ce0b5a438ea43ca213a4` and Git tree `4d305c3f45cdf5882d00f0b6c3c1d2dc9a02d3bd`.

The branch-push child intentionally exited with code `75` after its external write; a new process reconciled the exact GitHub ref before the database marked the publication `CONFIRMED`. The draft-PR child also exited with code `75` after creation; a new process reconciled the saved PR before marking it `CONFIRMED`. The orchestration command was then invoked again after the local PostgreSQL server had stopped. It restarted that server, reloaded the same run, and found one candidate, one verification, one publication, and one draft PR. Independent GitHub readback confirmed PR #1 is still open and draft, by `binnukyadari`, with the pinned base/head SHAs and only the two expected files.

This is a scoped synthetic demonstration. The published candidate came from the saved Phase 1A artifact, not from the disposable Phase 1D repair run. The PR targets the feature branch because `main` does not yet contain the sample app. The pre-PR independent code-review condition in ADR 0001 remains unqualified; the draft is for human review and must not be merged automatically. Jira integration, operated database and artifact recovery, branch protection/CI, deployment, and arbitrary-task reliability remain open. The evidence lives on this separate branch so publishing it does not move the live run's pinned PR base commit.
